# Archived: Native SwiftUI prototype

This folder contains the original **iOS-only SwiftUI** RedactPDF implementation.

The production app is now **Flutter** (`lib/`, `android/`, `ios/`) so it runs on Android without a Mac and still builds for iPhone when you have Xcode.

Keep this archive for reference (Vision/PDFKit approaches, Superwall wiring patterns). Do not open `RedactPDF.xcodeproj` as the primary product.
